ATHAR – أثر

An Arabic Islamic educational app that shares daily stories about Prophets and Companions.

Main features

- Daily Islamic stories
- Lessons and practical challenges
- Favorites
- Reading history
- Achievements
- Arabic RTL support

Android project goal

Build an Android APK that loads the existing ATHAR web app and supports Google AdMob using the official Google Mobile Ads SDK.
